#### 2.1源码-》可执行程序

```shell
# 预编译
gcc -E hello.c -o hello.i
#编译，得到汇编代码
gcc -S hello.i -o hello.s
#汇编
as hello.s -o hello.o
#链接
gcc hello.o -o hello
#or，使用ld需要手动添加一些库的位置链接
ld -o hello hello.o
```

#### 2.2编译器做了什么

* 词法分析 lex
* 语法分析 yacc
* 语义分析 

#### 2.3链接器

* 机器语言中没有符号，无法声明变量，一个多处引用的值如果发生改变，需要手动更改多处
* 汇编的出现，符号（Symbol）的概念普及和使用
