#### 下载

* [andrew-d/static-binaries: Various *nix tools built as statically-linked binaries](https://github.com/andrew-d/static-binaries)   有一些编译好的工具
* [Index of /](https://bin.entware.net/) opkg

```shell
# 1. 安装 Entware
wget -O - http://bin.entware.net/aarch64-k3.10/installer/generic.sh | sh

# 2. 配置环境变量
export PATH=/opt/bin:/opt/sbin:$PATH

# 3. 安装 gcc
opkg install gcc gdb
```
